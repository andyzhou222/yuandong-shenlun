# 申论逐题批改 Skill

一个参考公考袁东老师公开教学框架、用于逐题批改申论答案的独立学习辅助工具。支持概括、分析、对策、公文和大作文，重点说明材料要点在哪里、你的答案命中了什么、漏了什么以及怎样改。

这不是袁东老师本人或其课程的官方产品，也不提供真实阅卷分数。仓库只包含原创整理的批改指令和公开来源索引；不包含付费讲义、课堂答案或个人文件。

## 使用

将本仓库文件夹放入 Codex 的技能目录 `~/.codex/skills/yuandong-shenlun/`，然后发送：

> 用 `$yuandong-shenlun` 批改这道申论题。题干：…… 材料：…… 我的答案：……

若题目有分值、字数要求、参考答案或你自己的课堂笔记，一并提供。材料不完整时，skill 只会做能核实的部分，不编造采分点或精确分数。

方法出处和适用边界见 [公开来源](references/source-basis.md)。
